# 🤖 Telegram Chat Analyzer Bot

AI-бот для автоматического анализа рабочих чатов в Telegram. **Поддержка бесплатных AI моделей!**

## 📋 Описание

Этот бот мониторит ваш рабочий чат в Telegram (включая все топики), собирает сообщения, анализирует их с помощью AI и предлагает конкретные рекомендации по оптимизации рабочих процессов. Отчёты автоматически отправляются в личные сообщения 2 раза в неделю.

## ✨ Возможности

- 📊 **Мониторинг чатов** - автоматический сбор сообщений из всех топиков
- 🤖 **AI-анализ** - глубокий анализ коммуникации с помощью передовых AI моделей
- 🆓 **Бесплатные опции** - поддержка Groq, Gemini, Ollama (бесплатно!)
- 💡 **Рекомендации** - конкретные предложения по улучшению процессов
- 📨 **Личные отчёты** - результаты анализа отправляются вам в личку
- ⏰ **Автоматизация** - анализ выполняется 2 раза в неделю по расписанию
- 🔒 **Конфиденциальность** - все данные хранятся локально

## 🎯 Что анализирует бот

## 🚀 Установка

### Требования

- Python 3.9+
- Telegram Bot Token
- AI Provider (выберите один):
  - **Groq** (бесплатно, рекомендуется) ⭐
  - **Google Gemini** (бесплатно)
  - **Ollama** (локально, бесплатно)
  - **Claude** (платно, премиум качество)

📖 Подробнее про AI провайдеры: [AI_PROVIDERS.md](AI_PROVIDERS.md)

### Шаг 1: Клонирование репозитория

```bash
git clone <repository-url>
cd team-tasks-optimiser
```

### Шаг 2: Установка зависимостей

```bash
# Создать виртуальное окружение
python -m venv venv

# Активировать виртуальное окружение
# Linux/Mac:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt
```

### Шаг 3: Создание Telegram бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный **Bot Token**

### Шаг 4: Получение AI API ключа (БЕСПЛАТНО!)

**Рекомендуем Groq** - полностью бесплатно и быстро! ⭐

1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com/)
2. Перейдите в "API Keys" → "Create API Key"
3. Сохраните ключ

**Другие варианты:**
- [Google Gemini](https://makersuite.google.com/app/apikey) - бесплатно
- [Ollama](https://ollama.com/) - локально, не нужен API ключ
- [Claude](https://console.anthropic.com/) - платно, премиум

📖 Подробные инструкции для каждого провайдера: [AI_PROVIDERS.md](AI_PROVIDERS.md)

### Шаг 5: Получение вашего Telegram User ID

1. Найдите бота [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте ему любое сообщение
3. Он пришлёт вам ваш User ID

### Шаг 6: Конфигурация

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Bot Token от @BotFather
TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

# AI Provider (groq - бесплатно и быстро!)
AI_PROVIDER=groq
AI_API_KEY=gsk_ваш_ключ_от_groq

# Ваш Telegram User ID
ADMIN_USER_ID=123456789

# База данных (можно оставить по умолчанию)
DATABASE_URL=sqlite:///./chat_analyzer.db

# Расписание анализа (по умолчанию: понедельник и четверг в 10:00)
ANALYSIS_SCHEDULE_DAY_1=0  # 0=Понедельник, 6=Воскресенье
ANALYSIS_SCHEDULE_TIME_1=10:00
ANALYSIS_SCHEDULE_DAY_2=3  # Четверг
ANALYSIS_SCHEDULE_TIME_2=10:00

# Настройки анализа
ANALYSIS_DAYS_BACK=7  # Анализировать сообщения за последние 7 дней
MIN_MESSAGES_FOR_ANALYSIS=10  # Минимум сообщений для анализа
```

## 📱 Использование

### 1. Добавление бота в рабочий чат

1. Откройте ваш рабочий чат в Telegram
2. Нажмите на название чата → "Add Members"
3. Найдите вашего бота и добавьте его
4. **Важно:** Сделайте бота администратором чата, чтобы он мог читать все сообщения

### 2. Команды бота

В личных сообщениях с ботом или в чате:

- `/start` - приветствие и описание
- `/help` - помощь и документация
- `/status` - статус мониторинга (сколько сообщений собрано)
- `/analyze` - запустить анализ вручную (только для админа)

### 3. Получение отчётов

Бот автоматически будет отправлять вам отчёты в личные сообщения 2 раза в неделю согласно расписанию в `.env`.

Вы также можете запустить анализ вручную командой `/analyze` в чате.

## 🔧 Расширенная настройка

### Изменение расписания анализа

В `.env` можно настроить любые дни и время:

```env
# Например, каждый вторник и пятницу в 14:30
ANALYSIS_SCHEDULE_DAY_1=1  # Вторник
ANALYSIS_SCHEDULE_TIME_1=14:30
ANALYSIS_SCHEDULE_DAY_2=4  # Пятница
ANALYSIS_SCHEDULE_TIME_2=14:30
```

Дни недели:
- 0 = Понедельник
- 1 = Вторник
- 2 = Среда
- 3 = Четверг
- 4 = Пятница
- 5 = Суббота
- 6 = Воскресенье

### Использование PostgreSQL вместо SQLite

Измените `DATABASE_URL` в `.env`:

```env
DATABASE_URL=postgresql://user:password@localhost/chat_analyzer
```

## 🐳 Развёртывание с Docker

Создайте `Dockerfile`:

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "main.py"]
```

Создайте `docker-compose.yml`:

```yaml
version: '3.8'

services:
  bot:
    build: .
    env_file:
      - .env
    volumes:
      - ./data:/app/data
    restart: unless-stopped
```

Запуск:

```bash
docker-compose up -d
```

## 🐛 Решение проблем

### Бот не видит сообщения в чате

- Убедитесь, что бот добавлен как **администратор** чата
- Проверьте, что у бота есть права на чтение сообщений

### Бот не отправляет отчёты

- Проверьте правильность `ADMIN_USER_ID` в `.env`
- Убедитесь, что вы начали диалог с ботом (`/start`)
- Проверьте логи: `tail -f bot.log`

### Ошибка API

- Проверьте валидность `ANTHROPIC_API_KEY`
- Убедитесь, что у вас есть кредиты на балансе Anthropic
- Проверьте соединение с интернетом

### Мало сообщений для анализа

- Подождите, пока накопится больше сообщений
- Уменьшите `MIN_MESSAGES_FOR_ANALYSIS` в `.env`
